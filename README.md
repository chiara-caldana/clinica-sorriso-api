O cliente é uma clínica de odontologia. O sistema organiza a agenda de consultas (paciente, data, horário e dentista) e mostra os horários livres e ocupados. Ao cancelar uma consulta ou registrar uma falta, ele libera o horário e anota a ausência no prontuário. Também guarda o histórico clínico de cada paciente e reserva as manhãs de sábado para pacientes VIP. A identidade visual é azul-marinho e prata.
